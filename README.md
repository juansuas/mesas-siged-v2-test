# Mesas SIGED · Versión 2.0 de prueba

Sitio estático de las Mesas de diálogo para el fortalecimiento de los SIGED en Argentina.

- Repositorio público de prueba: https://github.com/juansuas/mesas-siged-v2-test
- Sitio de prueba: https://juansuas.github.io/mesas-siged-v2-test/
- Versión 2.0: [OES-UNIPE](https://observatorio.unipe.edu.ar/).
- [Banco de Indicadores e Índices Educativos](https://juansuas.github.io/banco-indicadores-educativos/).

## Publicación

GitHub Pages publica la raíz de la rama `main`. No requiere instalación, compilación ni servicios externos para mostrar los contenidos locales. `.nojekyll` conserva la publicación directa de los archivos estáticos.

El administrador, el Excel editable, los borradores, los respaldos y los archivos originales de carga permanecen en el entorno local. Este repositorio contiene el resultado estático generado para consulta. La carga y edición no funcionan en GitHub Pages: los cambios se preparan localmente y luego se actualizan en este repositorio.

## Contenidos

Incluye 24 jurisdicciones, 25 desplegables, 14 publicaciones y 10 mesas. La clasificación territorial reproduce la versión anterior y no implica una actualización del relevamiento. Los resúmenes de publicaciones están desactivados; el campo se conserva para uso futuro y no es obligatorio cargarlos; la séptima mesa no tiene minuta disponible.

Los documentos y enlaces institucionales conservan sus respectivas fuentes y autorías.
